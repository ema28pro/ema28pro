### What I've been building

**[obsidian-skip-silence](https://github.com/ema28pro/obsidian-skip-silence)** — An Obsidian plugin that detects silence in video/audio and skips it automatically. Custom speed controls for dead time so note-taking doesn't feel like watching paint dry.

**[discord-plugin-photoshop-2020](https://github.com/ema28pro/discord-plugin-photoshop-2020)** — A CEP extension wired to Node.js that broadcasts your Photoshop canvas state to Discord in real time. Layer count, document size, what you're working on — all live.

**[agente-inventario-mercado-central](https://github.com/ema28pro/agente-inventario-mercado-central)** — A LangChain agent backed by Gemini that lets you query supermarket inventory spreadsheets in plain Spanish. Ask it "¿cuántas unidades de arroz quedan?" and it answers.

**[manga-downloaders](https://github.com/ema28pro/manga-downloaders)** — Tampermonkey scripts that batch-download manga chapters and zip them up. Because reading offline shouldn't require 47 clicks.

### Things I've learned recently that I can't stop thinking about

- `NaN != NaN` — IEEE 754 breaks reflexive equality and it's by design
- `a[i] == i[a]` — pointer arithmetic in C is commutative: `*(a + i)` = `*(i + a)`
- `OffscreenCanvas` — you can do graphics work in a Web Worker without blocking the UI thread
- `Lost in the Middle` — LLMs literally lose attention in the center of long contexts
- `Discord RPC` — the Rich Presence API is a rabbit hole I'm happily stuck in
